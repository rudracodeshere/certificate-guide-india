Privacy: what this site records

This site has no accounts, no forms that send data and no ads, and it sets no cookies. Visits are counted with GoatCounter, a privacy-friendly counter, and the pages are hosted on GitHub Pages. Nothing you type into the certificate calculator leaves your browser.

What GoatCounter counts

According to the GoatCounter privacy policy (checked 27 October 2026):

  • It stores counts of the page path, the referrer, the browser and operating system name and version, the country (worked out from the IP address), the language and the screen size.
  • It does not store IP addresses, the full browser User-Agent or any tracking ID, and it stores nothing in your browser: no cookies and no localStorage.
  • To tell a new visit from a repeat one, it keeps a record of the site, IP address and User-Agent in memory for up to 8 hours.
  • It says it does not share this information with third parties.

The counter is shared with our sister site, Where to Complain, and the two sites are told apart by the page path. It does not see the dates you type into the calculator. You can block the counter with any content blocker. The site works the same without it.

What the host records

The site is served by GitHub Pages. GitHub's documentation says that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes (What is GitHub Pages?, checked 26 October 2026). See the GitHub General Privacy Statement for more.

What we never ask for

We never ask for your documents, Aadhaar number, application ID, passwords, OTPs or money. The calculator runs only in your browser and saves nothing. Official sites linked from our guides, such as Aaple Sarkar, have their own privacy policies.

Questions or corrections

Open an issue at https://github.com/rudracodeshere/certificate-guide-india/issues. Issues are public, so do not post personal details there.
